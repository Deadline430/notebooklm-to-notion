# Course Study Workflow Example

This example shows how to use the skill for a general university course.

## User Request

```text
Use notebooklm-to-notion.

NotebookLM notebook: Machine Learning Foundations
Notion parent page: Machine Learning Foundations

Use the lecture transcript source, textbook source, and assigned paper source to create learning materials for:
- Week 3 Lecture + Textbook Chapter 4
- Week 4 Lecture + Textbook Chapter 5
- Week 5 Lecture + Assigned Research Paper

For each part:
- Generate bilingual English-Chinese structured notes.
- Save the notes as a Notion weekly study child page.
- Generate a Chinese deep dive audio overview in NotebookLM Studio.
```

## Expected Notion Page Pattern

Each lesson page should use:

```text
### 1. Lesson Overview (课程概述)
### 2. Core Concept Glossary (核心概念)
### 3. Major Theories & Analogies (主要理论与类比)
### 4. Defects & Discussion Points (局限与讨论点)
### 5. Study Key Points (学习要点)
```

## Expected Audio Artifact Pattern

```text
Week 3 Lecture + Textbook Chapter 4 中文 Deep Dive Audio
Week 4 Lecture + Textbook Chapter 5 中文 Deep Dive Audio
Week 5 Lecture + Assigned Research Paper 中文 Deep Dive Audio
```
