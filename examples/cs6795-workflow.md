# CS6795 Example Workflow

This example shows how to use the skill for a cognitive science course.

## User Request

```text
Use notebooklm-to-notion.

NotebookLM notebook: CS6795 Intro to Cog Science
Notion parent page: CS6795 Intro to Cog Science

Use the transcript source and Thagard book source to create learning materials for:
- Lesson 7 + Thagard Chapter 8
- Lesson 8 + Thagard Chapters 9 and 10
- Lesson 9 + Thagard Chapters 11 and 12

For each part:
- Generate bilingual English-Chinese structured notes.
- Save the notes as a Notion lesson child page.
- Generate a Chinese deep dive audio overview in NotebookLM Studio.
```

## Expected Notion Page Pattern

Each lesson page should use:

```text
### 1. Lesson Overview (课程概述)
### 2. Core Concept Glossary (核心概念)
### 3. Major Theories & Analogies (主要理论与类比)
### 4. Defects & Discussion Points (局限与讨论点)
### 5. Study Key Points (学习要点)
```

## Expected Audio Artifact Pattern

```text
Lesson 7 + Thagard Chapter 8 中文 Deep Dive Audio
Lesson 8 + Thagard Chapters 9-10 中文 Deep Dive Audio
Lesson 9 + Thagard Chapters 11-12 中文 Deep Dive Audio
```
